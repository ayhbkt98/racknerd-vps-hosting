## 網站代管是什麼？實際上幫你管了哪些東西

簡單說，網站代管就是把構成網站的所有檔案——程式碼、圖片、影片、資料庫——放到主機商提供的伺服器上，讓全世界的訪客都連得上你的網站。伺服器是一台全天候開機、持續連網的高性能電腦，買代管方案等於向它租一塊空間。沒有代管，網站就只是躺在你個人電腦裡的一堆檔案，外人看不到。

代管商負責的範圍依服務等級而不同：基本款至少包含伺服器的穩定運作、安全防護，以及訪客輸入網域時把檔案送到對方瀏覽器；等級高一點的，連主機軟硬體更新、防火防震機房、不斷電系統、24 小時資安監控都一起包了。台灣主機商像遠振資訊，就主打 ISO 27001 驗證機房與全天候工程團隊——你付的錢，買的其實是「不用自己操心」。

## 四種常見類型：差別在資源怎麼分、誰來管

網站代管大致分四種，先搞懂類型才不會買錯：

| 類型 | 運作方式 | 適合誰 |
| --- | --- | --- |
| 共用主機 | 一台伺服器塞數百個網站，彼此共用資源 | 新站、低流量個人網站，最便宜 |
| VPS | 共用實體機，但有自己的虛擬分區與保證資源 | 想要獨立環境、root 權限的人 |
| 專用伺服器 | 整台實體機租給你 | 高流量、高效能需求的大型網站 |
| 雲端代管 | 分散式網路，單點故障自動接手，資源彈性伸縮 | 流量起伏大的應用、技術團隊 |

前三種的架構都是單一伺服器，機器掛了網站就跟著掛；雲端代管靠備援網路換取更高的可用性，代價是按用量計費，流量一暴衝帳單也會跟著衝。對多數個人網站和中小企業來說，共用主機或小規格 VPS 就撐得住，不必一開始就往上跳。
